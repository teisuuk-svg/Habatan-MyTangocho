# 英単語トレーニング

添付Excelの822語を使った、GitHub Pages向けの静的4択学習アプリです。サーバーやデータベースは使わず、学習履歴と設定はブラウザのLocalStorageに保存します。

## 公開方法

このフォルダの内容をGitHubリポジトリのルートへ配置し、GitHub Pagesの公開元をリポジトリのルートに設定してください。すべて相対パスで参照しているため、リポジトリ名を含むサブパスでも動作します。

## ローカル確認

静的HTTPサーバーでこのフォルダを公開し、`index.html`を開いてください。ファイルを直接開く場合も主要機能は動作します。

## データ更新

`words.js`は、Excelの「はば単のみ」シートを`convert_excel.py`で機械変換したものです。単語・意味・品詞・用例・☆は元データを変更していません。

## テスト

Node.jsがある環境で、次を実行します。

```text
node test_logic.js
```
